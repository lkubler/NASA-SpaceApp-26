# Design
The visitor should understand: this is one calm mission tool, the same in every step.
Rests on: `docs/mockups/01` to `04`, `docs/design/helmet-frame.png`

Mockups => they set the look; the specs set the content. Where they differ, the spec wins. Values and terrain in the mockups are placeholders
Background => black
Terrain => the only large coloured area: Mars orange and brown
Text => white; secondary text grey
Headline => one large line per step, ending with a full stop: "Choose your mission.", "Plan your mission.", "Route ready."
Fonts => a geometric display face for headlines and big numbers, a plain sans for text, a mono face for values, codes and the project name; matched to the mockups
Project name => top left, mono capitals in square brackets
Accent => cyan: the route on foot, the selected item, the main action, a passed check
Too steep => hatched orange-brown area on the map
Warning levels => red, yellow, blue; only for warnings, cautions and advisories
Cards => rounded, thin border, dark fill; in the helmet translucent over the terrain
Markers => numbered circles, mono digits; the chosen one filled cyan
Main button => one per screen, a wide pill, bottom right; in the last step before the walk cyan with a glow
Map => a rounded panel on the left, legend below it, scale bar inside
Big numbers => label small and grey above, value large below
Helmet => `docs/design/helmet-frame.png` around the view; the green area is the scene
Labels real / model / simulated / assumption => small mono text beside the value
Motion => short fades and slides only

Not in this spec: logo, sound, a light theme.
