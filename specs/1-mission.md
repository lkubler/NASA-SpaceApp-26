# 1 Mission
The visitor should understand: Earth asks for one sample, the answer takes minutes to arrive, so the crew plans this excursion alone.
Rests on: `research/research-requests.md`, `research/walk-targets.md`

Opening => two sentences before anything else: a crew on Mars, up to 22 minutes of signal delay each way; one question: can I still get home?
Site => Murray Buttes in Gale crater; a small map shows where it lies; label: real
Requests => up to three cards from Earth: cross-beds in the sandstone, the contact between mudstone and sandstone, radiation next to a butte
Card => who asks, what sample, why it matters in one sentence, a real Curiosity photo
Wording => names the rock, not a point: "a sample from the sandstone at the base of the buttes"
One sample => each request asks for exactly one
Signal delay => shown on the panel with the time the request was sent
Request without a reachable spot in the site => not shown
Choosing => one request; the main button leads to Plan

Not in this spec: launch, landing, regional map, rover drive, other sites, devices to place.
