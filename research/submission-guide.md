## Additions that matter (not in CLAUDE.md)
- Submission opens Sat 14.11. 09:00 local. The "Project" tab appears under My Team at that time. Save often ("Save Progress").
- Required form fields: Project Name; High-Level Project Summary; Link to Project Demo; Link to Final Project; Detailed Project Description (what it does, how it works, benefits, tools used); Use of SI; NASA Data; Space Agency Partner Data and Other References.
  Submit is blocked if any required section is empty.
- Two checkboxes at submit: Terms and Conditions; "Confirm All Work is Original".
- Only the last saved submission is judged. Resubmitting is allowed. Anything saved or submitted after the deadline is ineligible.
- Edit lock: the lock toggle can be overridden by teammates, so only one person edits at a time.
- Images on the project page: JPG, PNG or GIF, up to 10 MB each (CLAUDE.md lacks the formats). Videos and documents cannot be uploaded; link them.
- Link rules: public, with no login, permission or registration. Test in a private window.
  If the team hosts its own website, the guide recommends a free FortiGuard Web Filter Classification request (Company Name "N/A") so judges' networks do not block it. Optional.
- Demo: 30 s video or 7 slides including title and intro. Exceeding either limit makes the project ineligible for Global Judging.
  A slide demo must show team name, member names and the chosen challenge, an image of the project, the user experience, and how NASA and agency data make it possible.
  Suggested video timing: intro 0:00, challenge 0:02, title and tagline 0:05, idea and data 0:10, future 0:20-0:30.
  The demo counts in the overall evaluation, but most of the judging is based on the project page. Fill in the page carefully.
- SI disclosure: the form's SI question is for data collection only and judges do NOT see the answer.
  What judges see are the watermarks, descriptive text and metadata inside the project.
  So disclose AI use also in the Detailed Description and References, not only in that field. See `docs/ai-use.md`.
  Generated images and video need a visible watermark. Audio, code and data need a note in descriptive text and metadata.
  No NASA logos, flags or mission identifiers in generated content.
- References field: list all data, code, text and images used, even open source. Copyrighted material needs permission.
  Space agency partner data is encouraged. ESA is on the 2026 partner list.
- NASA Data field: give specifics. At least one NASA dataset or resource is required for Global Awards.
- Under-18 rule: no images, video, audio or likeness of persons under 18 in the demo or project. Check the team photo and slide credits.
- Team: all members confirmed at the same Local Event (not waitlisted). Max 6 members (see `docs/rules-2026.md`).
- Certificate: it only appears after "Submit for Judging", under Profile > Participant Information. The Full Name field sets the name printed on it.
