# Usable Mars datasets for a 27 h prototype

Author: data-scout, Sat 14.11. ~12:40-13:00. Everything marked TESTED was hit with curl from this machine on that day. "CORS" = response had `Access-Control-Allow-Origin` for an arbitrary Origin (browser fetch from our site works).
Context: notes.md main site = Gale Crater / Murray Buttes (Curiosity, Aug-Sep 2016), flow = 2D route planning on slope/obstacles + 3D first-person EVA + HUD (radio shadow, return reserve, radiation, weather).

## Bottom line (smallest set for a prototype)
1. **HiRISE DTM `DTEEC_009650_1755_009716_1755_U01`** (1 m/px, real elevation floats) = the only real source for slope, roughness, line-of-sight (radio shadow), return-reserve cost. Fetch a window by HTTP Range, preprocess offline into a small PNG/Float32 grid committed to the repo.
2. **HiRISE orthoimage** (25 cm / 1 m) for the 2D map backdrop and obstacle look.
3. **Mars Trek WMTS tiles** for context layers (Gale CTX mosaic, HiRISE Curiosity mosaic, TES thermal inertia, THEMIS) - zero auth, CORS open, directly usable in Leaflet/OpenLayers.
4. **Access Mars terrain** (Apache-2.0, `terrain.glb` + tiles) for the 3D first-person view, optional if we build our own mesh from (1).
5. **Curiosity REMS (PDS Atmospheres, plain files) + Mars Climate Database HTTP endpoint** for weather window; **Curiosity RAD** for dose (access path NOT verified, see below). Precompute these into a tiny JSON; do not call live from the browser.
Skip for the prototype: CRISM raw, SWIM, MEDA, InSight API, Worldview (Earth only).

## Trek layers worth using (ids from the catalog, capabilities TESTED = 200 unless noted)
- `Gale_DEM_SMG_1m` (MRO HiRISE Gale Crater DEM) - tiles are 8-bit gray+alpha, i.e. shaded/gray render, **not usable for elevation values**. Bbox starts at 137.12E, -4.93N. Max zoom 14.
- `curiosity_hirise_mosaic` (HiRISE Curiosity roving-site mosaic, max zoom 16, real imagery). Best 2D basemap on Trek.
- `Gale_CTX_BlockAdj_dd` (CTX Gale mosaic, max zoom 12, ~6 m).
- `mars_pahrump_patch_8k_256m` (MSL Pahrump Hills patch, max zoom 18).
- `TES_Thermal_Inertia`, `mola_roughness` (global, zoom 1 only, very coarse).
- `THEMIS_DayIR_ControlledMosaics_100m_v2_oct2018`, `THEMIS_NightIR_ControlledMosaics_100m_v2_oct2018`, `Mars_MGS_MOLA_ClrShade_merge_global_463m` (all TESTED).
- 404 for my guessed ids: `Mars_MRO_CTX_Mosaic_Beyer_Global_5mpp`, `Mars_MGS_MOLA_Shade_global_463m`, `Mars_MOLA_blend200ppx_HRSC_DEM_clon0dd_200mpp_lzw`, `MSL_Gale_Orthophoto_Mosaic_10m`. Use ids from the catalog only (the `productLabel` field is not always the tile folder name).

## Caveats
- Trek tiles give images, not numbers. Slope/LOS must come from the HiRISE DTM (or a MOLA/HRSC blend for other sites; the 200 m MOLA-HRSC DEM did not resolve on Trek in my test).
- The HiRISE DTM is a 2010 USGS SOCET product; see https://www.uahirise.org/dtm/about.php for vertical-error notes (not read in full).
- The challenge's own Resources page says not to assume non-US sites are endorsed; Mars Climate Database and Access Mars are non-NASA, cite them with their licenses.
- Nothing downloaded to `data/raw/`; only headers, 1-3 KB range reads and capabilities files were fetched.
