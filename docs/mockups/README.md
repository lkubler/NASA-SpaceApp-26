# UI mockups

Screen designs for the mission flow (see `Mission_flow.md`), in order:

1. `01-choose-mission.png`: pick a site in Gale Crater (Murray Buttes, Marias Pass, Pahrump Hills)
2. `02-plan-route.png`: plan rover + on-foot route, stops, infrastructure site
3. `03-route-overview.png`: route summary, elevation profile, EVA checklist
4. `04-helmet-view.png`: 3D mission in helmet view with HUD

Values and terrain in the mockups are placeholders.
